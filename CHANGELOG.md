## [0.1.0] - 2024-XX-XX

### Ajouté
- Interface TUI dans le navigateur avec Ratzilla et WebAssembly
- Support multi-types d'audits (Technique, Business, Marketing, Autre)
- Système de catégories organisées (Infra, Opération, DB, A11y, Archi, Intra, OSS, Dev XP, Produit, Sécu, Bizdev, Organisation)
- Chargement de questions depuis fichiers YAML
- Système de réponses flexibles (Oui, Non, Je ne sais pas, Non applicable avec pourcentages optionnels)
- Génération automatique de recommandations basées sur les réponses
- Stockage local dans le localStorage du navigateur
- Export/Import d'audits (TXT et YAML)
- Rapports et statistiques par catégorie
- 45 tests unitaires avec couverture complète
- Support du déploiement sur Vercel, Netlify et GitHub Pages

### Documentation
- README complet avec instructions d'installation et d'utilisation
- Documentation des raccourcis clavier
- Guide de structure des données
- Instructions de déploiement
